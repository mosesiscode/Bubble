> **Contributions Policy:** Public Pull Requests are disabled. Please report bugs via the Issues tab, or fork the repository for custom features.

## Features
- Supports local music files, synced/fullscreen lyrics, and streaming/imports from YouTube, YouTube Music, SoundCloud, Spotify data, and Apple Music.

## Run & Build
- **Run:** Install dependencies via `pip install -r requirements.txt` and run `python app.py`.
- **Build:** Execute `build.bat` (Windows) or `./build.sh` to generate the executable in `dist/`.

## Notes
- Settings are stored locally in `~/.bubbleplayer.json`. The app is not affiliated with Spotify, Apple, YouTube, or SoundCloud.
- This app is known to bkarv false positives
